# Deployment Checklist

Use this checklist before deploying a smart contract.

- [ ] Review the contract code
- [ ] Compile the contract
- [ ] Run tests
- [ ] Check constructor parameters
- [ ] Verify the deployment network
- [ ] Confirm the deployer wallet
- [ ] Review gas requirements
- [ ] Save the deployed contract address
- [ ] Verify the contract when appropriate

Never deploy untested code with valuable assets.
