# Blockchain Glossary

## Block

A group of transactions recorded on a blockchain.

## Wallet

Software or hardware used to manage blockchain accounts and sign transactions.

## Smart Contract

Program code deployed on a blockchain.

## Gas

A measurement of computational work used to process transactions.

## Transaction

A signed request submitted to a blockchain network.

## EVM

The Ethereum Virtual Machine executes Ethereum-compatible smart contracts.

## Layer 2

A network built to improve scalability while connecting to an underlying blockchain.
