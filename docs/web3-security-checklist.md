# Web3 Security Checklist

Security should be considered throughout the development process.

## Checklist

- [ ] Protect private keys.
- [ ] Verify contract addresses.
- [ ] Review transaction parameters.
- [ ] Test smart contracts.
- [ ] Review access controls.
- [ ] Handle failed transactions.
- [ ] Keep dependencies updated.
- [ ] Avoid signing unknown transactions.

Security reviews should be performed before applications are used with valuable assets.
