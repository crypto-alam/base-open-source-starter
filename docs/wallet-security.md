# Wallet Security

Wallet security is essential when interacting with blockchain
applications.

## Security Practices

- Keep seed phrases private.
- Never share private keys.
- Verify websites before connecting a wallet.
- Review transaction details before signing.
- Avoid signing transactions you do not understand.
- Use separate wallets for development and valuable assets when
  appropriate.

Blockchain transactions can be difficult or impossible to reverse,
so careful verification is important.
