# Development Checklist

Use this checklist when developing a blockchain application.

## Before Development

- Understand the project requirements.
- Review the existing code.
- Select appropriate development tools.

## During Development

- Write clear code.
- Test functionality.
- Review security considerations.
- Keep documentation updated.

## Before Deployment

- Run tests.
- Review configuration.
- Protect private credentials.
- Confirm the target network.
- Review the final transaction.

## After Deployment

- Record the contract address.
- Verify the deployment where possible.
- Test basic interactions.
- Monitor the application.
