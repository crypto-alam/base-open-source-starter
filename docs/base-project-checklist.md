# Base Project Checklist

Use this checklist when building a project for Base.

## Development

- [ ] Define the project requirements.
- [ ] Set up the development environment.
- [ ] Write the smart contracts.
- [ ] Test the contracts.
- [ ] Connect the application to the network.
- [ ] Test transactions.
- [ ] Review security considerations.
- [ ] Document the project.
- [ ] Prepare deployment information.

A clear checklist helps keep development organized from planning through deployment.
