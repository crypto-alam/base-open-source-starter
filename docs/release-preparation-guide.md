# Release Preparation Guide

A release should be prepared carefully before being published.

## Release Checklist

- [ ] Review recent changes.
- [ ] Test important functionality.
- [ ] Update documentation.
- [ ] Review the changelog when available.
- [ ] Check version information.
- [ ] Confirm deployment configuration.
- [ ] Prepare release notes.
- [ ] Review the final changes.

A clear release process helps contributors understand what changed.
