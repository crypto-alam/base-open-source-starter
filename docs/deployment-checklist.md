# Smart Contract Deployment Checklist

Use this checklist before deploying a smart contract.

## Code

- Review the Solidity source code.
- Compile the contract successfully.
- Check compiler settings.
- Review important functions.

## Testing

- Run unit tests.
- Test normal interactions.
- Test invalid inputs.
- Check important state changes.

## Network

- Confirm the target network.
- Confirm the RPC configuration.
- Confirm the deployment account.
- Make sure sufficient test funds are available when using a testnet.

## Security

- Never expose private keys.
- Never commit seed phrases.
- Review access control.
- Review external contract interactions.

## After Deployment

- Record the contract address.
- Verify the deployment when possible.
- Test basic contract interactions.
- Keep deployment information documented.
