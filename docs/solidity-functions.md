# Solidity Functions

Functions define actions that a Solidity smart contract can perform.

## Common Function Concepts

Functions can:

- Read contract state
- Modify contract state
- Accept parameters
- Return values
- Restrict access

## Visibility

Solidity functions can use visibility such as:

- `public`
- `external`
- `internal`
- `private`

Choosing appropriate visibility helps keep contract behavior clear
and reduces unnecessary access.
