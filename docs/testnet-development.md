# Testnet Development

Testnets provide an environment for experimenting with blockchain
applications before production deployment.

## Typical Workflow

1. Configure a testnet wallet.
2. Obtain testnet funds when available.
3. Deploy the contract.
4. Test contract functions.
5. Inspect transactions.
6. Fix issues.
7. Repeat testing as necessary.

Testnet environments are useful for learning and development because
they reduce the risk associated with experimenting on production
networks.
