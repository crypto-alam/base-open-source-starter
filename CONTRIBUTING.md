# Contributing

Thank you for your interest in contributing to this project.

## Getting Started

1. Fork the repository.
2. Create a new branch for your change.
3. Make your changes.
4. Test your changes.
5. Commit your work with a clear commit message.
6. Open a pull request.

## Commit Guidelines

Please use clear commit messages that describe the change.

Examples:

- `feat: add new contract`
- `fix: correct contract logic`
- `docs: improve documentation`
- `test: add contract tests`
- `chore: update configuration`

## Code Quality

Please keep contributions simple, readable, and well documented.
