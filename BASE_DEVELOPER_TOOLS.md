# Base Developer Tools

Developers building on Base can use familiar Ethereum development tools.

## Solidity

Solidity is commonly used to create smart contracts compatible with the Ethereum Virtual Machine.

## Foundry

Foundry provides tools for building, testing, and deploying smart contracts.

## Hardhat

Hardhat is a popular Ethereum development environment for compiling, testing, and deploying contracts.

## MetaMask

MetaMask can be used to connect a wallet to Base and interact with decentralized applications.

## Summary

These tools help developers build, test, and interact with applications on Base.
